# 📦 Sistema de Controle de Estoque e Logística

> Aplicação web para otimização de fluxo logístico e controle de estoque. Desenvolvida com HTML, CSS e JavaScript, oferece dashboard dinâmico, registro de movimentações e atualização de inventário em tempo real. O projeto reflete a união entre desenvolvimento de sistemas e soluções práticas para gargalos do setor de suprimentos.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica da aplicação.
* **CSS3 (Flexbox):** Interface responsiva, moderna e focada na usabilidade do operador.
* **JavaScript (Vanilla):** Manipulação do DOM para injeção de dados na tabela e cálculos em tempo real sem recarregar a página.

## ⚙️ Funcionalidades
- [x] Dashboard dinâmico com métricas de entradas e saídas.
- [x] Formulário de registro de movimentações logísticas com validação.
- [x] Tabela de inventário atualizada instantaneamente.
- [x] Geração automática de códigos SKU para novos registros.
